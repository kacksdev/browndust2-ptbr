# Contribuição

Este repositório é uma vitrine documental. O mod e seus arquivos de implementação não estão disponíveis para contribuição pública neste estágio.

## O que pode ser enviado

- Correção de informação incorreta ou desatualizada na documentação.
- Sugestão de clareza, acessibilidade ou organização.
- Fonte oficial relevante para uma afirmação pública.

Use um dos formulários em **Issues**. Não publique arquivos do jogo, credenciais, logs com dados pessoais, catálogos extraídos, links para cópias não autorizadas ou instruções de contorno de proteção.

## Pull requests

Pull requests externos podem ser analisados, mas não modificam o repositório sem revisão e aceite explícito do proprietário. Alterações na branch principal são protegidas e o arquivo `CODEOWNERS` exige revisão de `@kacksdev`.

PRs não solicitados que incluam binários, conteúdo proprietário, código do mod ou mudanças fora do escopo documental poderão ser fechados.

## Código de conduta

Seja direto, respeitoso e mantenha a discussão no projeto. Assédio, pressão por builds privados ou divulgação de dados pessoais não serão aceitos.
