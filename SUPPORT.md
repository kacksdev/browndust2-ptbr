# Suporte

- Para instalar ou remover, consulte [`docs/INSTALACAO.md`](./docs/INSTALACAO.md).
- Para confirmar a versão testada, consulte [`docs/COMPATIBILIDADE.md`](./docs/COMPATIBILIDADE.md).
- Para erros reproduzíveis, abra uma [Issue](https://github.com/kacksdev/browndust2-ptbr/issues/new/choose).
- Para vulnerabilidades, use o [relato privado](https://github.com/kacksdev/browndust2-ptbr/security/advisories/new).

Inclua sempre as versões do mod e do cliente. Não envie dados de conta, credenciais, saves ou arquivos proprietários do jogo.
