# Segurança

## Escopo

Este repositório contém somente documentação e imagens públicas. Não há executável, DLL, catálogo traduzido, instalador, workflow de build ou pacote do mod.

## Relato privado

Se encontrar uma credencial exposta, dado pessoal, link indevido ou problema de segurança nesta documentação, não abra uma Issue pública. Use o [relato privado de vulnerabilidade](https://github.com/kacksdev/browndust2-ptbr/security/advisories/new).

## Fora do escopo

- Vulnerabilidades do próprio Brown Dust 2 ou dos serviços da empresa.
- Solicitação de acesso ao repositório privado de desenvolvimento.
- Pedido de binários, catálogos ou versões ainda não publicadas.
- Técnicas para contornar autenticação, proteção ou segurança do jogo.

Problemas do jogo devem ser enviados aos canais oficiais do produto.
