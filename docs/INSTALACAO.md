# Instalação, atualização e remoção

## Antes de começar

- Use somente a versão de PC / Windows.
- Atualize o jogo pelo lançador oficial e feche o cliente.
- Baixe o pacote pronto na seção [Releases](https://github.com/kacksdev/browndust2-ptbr/releases), não pelo botão `Code`.
- Não execute o instalador de dentro do arquivo ZIP.

## Instalar

1. Extraia `BD2PTBR-v0.1.0.zip` para uma pasta comum.
2. Abra a pasta extraída.
3. Execute `INSTALAR-BD2-PTBR.cmd`.
4. Se a instalação do jogo não for encontrada, selecione a pasta que contém `Brown Dust II.exe`.
5. Aguarde a confirmação e abra o jogo normalmente.

O instalador valida o pacote, localiza o cliente, cria uma cópia de segurança dos arquivos que serão alterados e instala o carregador, o plugin e o catálogo.

## Atualizar o mod

1. Feche o jogo.
2. Baixe a Release mais recente.
3. Extraia o novo ZIP em outra pasta.
4. Execute o novo `INSTALAR-BD2-PTBR.cmd`.

O instalador reconhece a versão anterior e cria um novo backup antes da substituição.

## Atualizar o jogo

1. Feche o cliente.
2. Abra o **Lançador BrownDust2** instalado com o jogo.
3. Conclua a atualização oficial.
4. Consulte a compatibilidade declarada na Release do mod.
5. Se necessário, reinstale a versão mais recente do mod.

A mensagem interna do jogo que pede uma versão mais recente do cliente não significa, por si só, que o mod bloqueou a atualização. O executável do jogo inicia o cliente; as atualizações são gerenciadas pelo lançador oficial.

## Remover

1. Feche o jogo.
2. Execute `REMOVER-BD2-PTBR.cmd` no pacote extraído.
3. Confirme a instalação que deve ser limpa.

O removedor apaga apenas os componentes conhecidos do mod e restaura os arquivos originais a partir do backup quando necessário. Saves e arquivos de conta não são alterados.

## Diagnóstico rápido

- **O jogo continua em inglês:** confirme se o ZIP foi extraído e se a pasta escolhida contém `Brown Dust II.exe`.
- **O jogo foi atualizado:** reinstale apenas uma versão declarada compatível com o novo cliente.
- **O jogo não abre:** remova o mod, atualize/verifique o cliente pelo lançador oficial e envie o log solicitado na Issue.
- **Texto novo em inglês:** registre a tela e a versão do cliente; conteúdo novo pode ainda não existir no catálogo.

Não publique saves, tokens, credenciais ou logs completos com dados pessoais.
