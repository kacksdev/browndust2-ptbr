## Política após atualizações

O plugin não modifica o sistema de atualização do Brown Dust 2. O cliente deve ser atualizado pelo lançador oficial.

Quando o jogo muda:

1. arquivos do cliente podem ser substituídos pelo atualizador;
2. textos novos podem não existir no catálogo do mod;
3. nomes internos ou assinaturas podem mudar;
4. a compatibilidade precisa ser testada novamente.

O runtime valida a integridade do catálogo e a existência dos pontos essenciais antes de permanecer ativo. Se uma dependência central falhar, os patches são removidos e o idioma original é preservado. Esse comportamento reduz o risco de deixar o cliente em estado parcial, mas não constitui promessa absoluta para versões futuras desconhecidas.

Sempre consulte a Release mais recente antes de reinstalar o mod depois de uma atualização do jogo.
