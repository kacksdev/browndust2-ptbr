# Brown Dust 2 PT-BR 0.1.0

## Versão retirada

A distribuição `0.1.0` foi retirada antes da continuidade da divulgação pública. O atalho de instalação procurava o script principal na pasta errada e podia exibir uma confirmação de sucesso mesmo sem instalar o mod.

O catálogo e o plugin daquela versão não apresentaram falha estrutural, mas o pacote não atendia ao padrão de instalação do projeto. Ele foi substituído integralmente pela versão `0.1.1`, que utiliza um instalador gráfico único, validação final obrigatória, rollback e testes sobre um cliente limpo real.

Não utilize arquivos antigos da versão `0.1.0`.
